# SQL Practice Scripts

This repository contains SQL practice scripts covering foundational query patterns used in data analysis and database work. The scripts focus on creating tables, inserting values, joining tables, using unions, and writing conditional logic with `CASE`.

## Files

| File | Topic |
| --- | --- |
| `creating_tables/sqlcodes_creatingtables` | Table creation practice |
| `sqlcodes_insertingvalues` | Insert statement practice |
| `sqlcodes_joins` | Inner, full outer, left, and right joins |
| `sqlcodes_union` | Combining query results with unions |
| `sqlcodes_case` | Conditional logic with `CASE` statements |

## Topics Covered

- Creating database tables
- Inserting records
- Joining employee demographic and salary tables
- Comparing join types
- Combining result sets
- Creating calculated categories using `CASE WHEN`

## Tools

- SQL Server
- SQL Server Management Studio

## Skills Demonstrated

- Relational database fundamentals
- SQL syntax practice
- Table joins and result set comparison
- Conditional query logic
- Query organization for learning and review
